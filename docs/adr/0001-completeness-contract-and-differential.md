# 功能完整性 = 契约完整 + 行为等价双轨验证

本项目硬性要求"100% 完整实现 ccxt 功能",我们将其操作化为两条可验证的轨道:契约测试(方法面 + 结构字段面 100% 覆盖,对选定交易所集合)作为发布门槛;与真实 ccxt 参考实现做差分对比测试(逐字段比对统一结构输出)作为持续质量手段,只对核心交易所常跑。选此方案是因为"完整"若不定义成可验证的契约,项目无法验收,而行为级逐字节等价既不可能也不需要。

- **Status**: accepted
- **Considered Options**: (a) 仅契约测试 — 覆盖面够但行为偏差无感知;(b) 仅差分测试 — 行为准但方法面缺口无人追;(c) 双轨(采用)。
